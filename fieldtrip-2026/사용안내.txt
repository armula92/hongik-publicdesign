1. 사진첩 열기
index.html을 웹 브라우저에서 여세요.
답사 기록집: index.html
전체 사진첩: gallery.html
인터넷 연결이나 별도 설치 없이 볼 수 있습니다.
HTML, CSS, JS 파일과 assets 폴더를 함께 보관하세요.
Google Drive에서는 폴더를 내려받아 브라우저로 여세요.

2. 감상 방법
- 스마트폰·작은 화면: 아래로 스크롤하며 감상합니다.
- PC·넓은 화면: 하단 이전/다음 버튼 또는 키보드 ← →로 넘깁니다.
- 하단 목차에서 원하는 장으로 바로 이동할 수 있습니다.
- 스마트폰의 전체 사진첩은 ‘사진 더 보기’로 24개씩 이어서 볼 수 있습니다.
- PC의 전체 사진첩은 이전/다음 버튼과 쪽수 선택으로 이동합니다.
- 사진을 누르면 크게 열리고, 좌우 버튼·키보드·터치로 넘길 수 있습니다.
- 대표 사진, 장소, 사진/영상으로 골라 보거나 검색할 수 있습니다.
- 영상은 누르면 소리와 함께 재생됩니다.
- 사진 425장과 영상 4개를 모두 수록했으며, 대표 사진은 60장입니다.
- 원본 파일은 상위 답사 폴더에 보존되어 있습니다.

3. 전공 웹사이트에 연결하기
이 폴더 전체를 웹 서버의 하위 폴더(예: /archive/gwangju-20261017/)에 올리세요.
전공 웹사이트 메뉴에서 해당 폴더의 index.html로 링크하면 됩니다.
상대 경로를 사용하므로 하위 폴더에서도 작동합니다.
서버 프로그램, 데이터베이스, 외부 CDN, API 키는 필요하지 않습니다.
웹 서버가 .webp, .mp4, .js, .css 파일을 제공하도록 설정하세요.
